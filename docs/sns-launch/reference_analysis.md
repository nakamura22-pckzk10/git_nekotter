# SNSローンチ用「LINE登録特典一覧画像」リファレンス分析

- 参照画像：`reference_osaru_30tokuten.jpg`（1821×2048px／約8:9の縦長）
- 用途：コンテンツ販売のSNSローンチで、X投稿に添付する画像
- 導線：X投稿 → 公式LINE登録 → LINE内で動画教育 → セミナー → 商品販売

---

## 0. 結論

この画像は「特典の一覧」に見えるが、実態は**X投稿の1枚にファネル全体（価値提供 → 教育 → セミナー → 個別相談 → 成約）を収めた販売導線の縮図**。

担う役割は3つだけ。

1. **スクロールを止める**：情報量と色数で、タイムライン上の異物になる
2. **登録しないと損だと思わせる**：原価の低い特典を大量に積み、知覚価値を膨らませる
3. **権威を一度に見せる**：各特典に実績数字を埋め込み、画像全体を実績集にする

画像の仕事は**LINE登録率を最大化すること**。売るのはLINEから先の仕事で、画像は売らない。

## 3. デザインの分解

### 3-1. 視覚階層（3層）

- **L1**：「公式LINE登録限定」＝行動
- **L2**：「30大特典プレゼント」＝見返り
- **L3**：個々の特典＝**読ませずに量として感じさせる**

1秒で伝わる内容は「LINE登録で30個もらえる」だけでよい。拡大した人だけが、自分に刺さる1〜2個を見つける設計。**全部は読めないこと自体が狙い**で、「とりあえず登録してから見よう」を誘う。

### 3-2. カラー

- 外枠（見出し・背景・番号バッジ）は**紫〜青のブランドカラーで統一**
- 特典バナーは**あえて1枚ずつ色を変える**（黒×ネオン、ピンク、ゴールド、水色など）
  → 統一感よりも「別々の商品が30個ある」感を優先し、バラバラさで物量感を強める
- 白丸＋紫の番号バッジ（特典01〜30）が、バラバラなバナーをひとつに束ねる

### 3-3. タイポグラフィ

- 見出し：極太の明朝/セリフ体＋グラデーション → 高級感と権威
- バナー内：極太ゴシック＋白フチ＋ドロップシャドウ → YouTubeサムネと同じ文法で視認性を最大化
- 「GPTs」の英字ロゴを繰り返し大きく置き、AIの記号として使う

### 3-4. コピーの型

各バナーは **［実績数字］＋［◯◯式］＋［成果物名］＋［形式］** でできている。

> 例：「総フォロワー70万人、累計60万リストを集客してきた」＋「おさる式」＋「コンセプト設計の極意」

- **実績数字をばらして置く**：0→1億→10億→30億／総フォロワー70万人／累計60万リスト／累計100億以上販売／4000RT・200万インプ／ROAS1,400%／一撃5.2億／10,000添削／累計9億売上／登録者30万人／月3.6億
  → 画像全体がプロフィール以上の実績ポートフォリオになる
- **労力ゼロを約束する言葉**：秒速／1分作成／ワンクリック／一撃／無限量産／完全再現／完全移植
- **「◯◯式」を繰り返す**：メソッドを固有のものにし、他と比べられなくする

## 4. LINE内での使われ方（推定）

- 特典は一度に全部渡さず、**リッチメニュー・キーワード応答・日次配信で少しずつ渡す** → 開封の習慣とシナリオ視聴を作る
- 特典受取を条件にして、動画視聴やアンケート回答を促す
- どの特典をタップしたかでタグを付け、**興味ごとにセグメントする**
- 特典29（無料相談）は、教育が済んだ層を個別相談枠へ流す出口

## 6. 株式投資ジャンル（銘柄攻略クラブ）への転用論点

### 真似るべき点

- 3層の視覚階層、番号バッジ、**並び順＝ファネル**、形式のMECEミックス、実績数字の分散配置
- 「媒体別」は投資ジャンルなら**スタイル別・フェーズ別**に置き換える
  - 例：決算分析／チャート／スクリーニング／ポートフォリオ管理／新NISA／初心者→中級者

### 真似るべきでない点・リスク

1. **物量の前提が違う**：参照元には実体のある資産が大量にある。数を水増しすると、登録後にがっかりされてブロック率が上がり、セミナー参加率が下がる。特典の数は「実在して、LINEで配れる数」で決める
2. **法規制（金融ジャンル固有）**
   - 有料サービスで個別銘柄を推奨する場合は、金商法の投資助言・代理業にあたるかが論点になる
   - 「超有料級」「◯万円相当」といった価値表示は、景品表示法の有利誤認リスクがある。根拠を示せる表現にとどめる
   - 投資成績（利益額・利回り）を訴求に使うと、再現性の誤認や断定的判断の提供と見られるリスクがある。「指導250人以上」などの事業実績を中心にする
3. **トーン**：投資ジャンルは「煽り＝詐欺」と連想されやすい。ネオンでギラついた見た目をそのまま持ち込むと信頼を損なう。**デザインの完成度は同じ水準、トーンは信頼寄り**に調整する
4. **人物素材**：参照元はマスクキャラ。顔出し・アイコン・キャラのどれで行くかを決める必要がある

## 7. 制作前に確定すべき情報

1. 特典の実体リスト（既存／新規作成）と数
2. LINEの先で何をいくらで売るか（コミュニティの月額／講座など）と、セミナーの有無・形式
3. ブランド（カラー・ロゴ・人物素材）
4. 使える実績数字（検証できるもの）
5. 投稿媒体（Xのみ／YouTube・インスタにも流用するか）
6. 制作手段（Canva／Figma／外注／AIで自作）
7. LINE配信ツール（UTAGE／Lステップなど）

## 8. AI・自動化での制作案

- **画像**：特典サムネと一覧画像を**HTML/CSSでテンプレ化し、ブラウザでPNGに書き出す**
  - テキストを差し替えるだけで量産・ABテストができる
  - 書籍の立体モックアップや人物写真の質感は画像生成AIの方が得意。日本語の文字は画像生成AIだと崩れやすいので、**背景と素材は画像生成AI、文字と組版はHTML**で分担する
- **特典（GPTs系）**：Claude Projects や GPTs で特典ツールそのものを作る
- **LINE配信**：UTAGEのMCP連携を使えば、特典の段階配布シナリオ・タグ付け・リッチメニューの設計から設定まで一気通貫で進められる
